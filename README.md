# Pitágoras Ops

## Sobre o Projeto

Pitágoras Ops é um jogo de sobrevivência desenvolvido em Python com Pygame, onde o jogador precisa enfrentar ondas crescentes de inimigos enquanto coleta moedas para comprar melhorias e armas.

## Instalação e Dependências

### Pré-requisitos
- Python 3.8 ou superior
- pip (gerenciador de pacotes do Python)

### Instalando as Dependências

```bash
pip install pygame
```

## Como Rodar o Jogo

1. Clone o repositório:
```bash
git clone https://github.com/nicolassaez2004/pygamedesoft2026.1.git
cd pygamedesoft2026.1
```

2. Certifique-se de que o Pygame está instalado

3. Execute o jogo:
```bash
python main.py
```

##  Como Jogar

### Controles:
- **WASD** ou **Setas** - Movimentar o personagem
- **Botão Esquerdo do Mouse** - Ataque corpo a corpo
- **Botão Direito do Mouse** - Atirar flecha (necessário ter arco e flechas)
- **ESC** - Pausar/Despausar o jogo
- **P** - Pausar/Despausar o jogo
- **ESPAÇO** - Pular tutorial

### Objetivos:
- Sobreviva o máximo de tempo possível
- Derrote inimigos para ganhar moedas e pontos
- Use as moedas para comprar equipamentos na loja (pressione E perto dos itens)
- Suba no placar de líderes com a maior pontuação

### Sistema de Loja:
Durante o jogo, você pode comprar:
- **Espada** - Aumenta a velocidade e a area de ataque
- **Arco** - Permite atirar flechas
- **Flechas** - Munição para o arco (3 tipos com diferentes efeitos)
- **Kit Médico** - Recupera vida (custo aumenta a cada compra)

## Sistema de Leaderboard

O jogo salva automaticamente as 10 melhores pontuações com os nomes dos jogadores. Acesse o placar através do menu principal ou após o game over.
